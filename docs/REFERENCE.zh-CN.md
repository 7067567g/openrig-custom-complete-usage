# 参考文档

本仓库是**完整使用例**。稳定的 SCTG 参考材料保留在
[`SCTG-public`](https://github.com/7067567g/SCTG-public)：

| 主题 | 位置 |
|---|---|
| 概念 / 协议 | `SCTG-public/docs/concepts.md`、`protocol.md` |
| Gate 语义 | `SCTG-public/docs/protocol.md`、`SCTG-public/kit/gates/` |
| Ledger / 决策 | `SCTG-public/docs/ledger.md`、`decision-model.md` |
| 模式策略 | `SCTG-public/docs/mode-policy.md` |
| 安全模型 | `SCTG-public/docs/security-model.md` |
| 术语 / FAQ | `SCTG-public/docs/glossary.md`、`faq.md` |
| 性能 | `SCTG-public/docs/performance.md` |
| 来源 / 状态 | `SCTG-public/docs/provenance.md`、`status.md` |

这个拆分是有意的：`SCTG-public` 负责稳定 kit 合同；本仓库负责
workflow-group 多轮编排和 OpenRig 执行层。
