# Reference docs

This repository is the **complete usage example**. The stable SCTG reference
material stays in [`SCTG-public`](https://github.com/7067567g/SCTG-public):

| Topic | Where |
|---|---|
| Concepts / protocol | `SCTG-public/docs/concepts.md`, `protocol.md` |
| Gate semantics | `SCTG-public/docs/protocol.md`, `SCTG-public/kit/gates/` |
| Ledger / decisions | `SCTG-public/docs/ledger.md`, `decision-model.md` |
| Mode policy | `SCTG-public/docs/mode-policy.md` |
| Security model | `SCTG-public/docs/security-model.md` |
| Glossary / FAQ | `SCTG-public/docs/glossary.md`, `faq.md` |
| Performance | `SCTG-public/docs/performance.md` |
| Provenance / status | `SCTG-public/docs/provenance.md`, `status.md` |

The split is intentional: `SCTG-public` owns the stable kit contract; this
repository owns workflow-group multi-round orchestration and OpenRig execution.
