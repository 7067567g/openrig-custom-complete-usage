# 通用契约 — 所有委派智能体必读

> 适用：PMO / TDO / QA / 安全关键 run 的 SAFETY，以及主会话（MAIN；主会话另见 `roles/MAIN.md`）。冲突裁决按 `WORKFLOW.md §0` 的权威链执行：用户当轮指令 > `WORKFLOW.md`（canonical） > `roles/*.md` > `templates/**` > `SPEC.md`（只能加严，不得放宽 §1 四条硬约束） > 非规范文档。

## 硬规则（16 条）

1. **文档是唯一交互源**：你的输入来自 run 目录文档，输出写回文档；不要在会话里长篇复述文档内容。
2. **只写自己名下的文档/账本**：PMO→`PROJECT.md`；TDO→当轮 `STATUS-Round-n.md`；QA→`ISSUES.xlsx`；主会话→`DECISIONS.md`（S0 bootstrap 窗口可填 `PROJECT.md §0` 元信息与 `§1` G1 目标/终止判据，PMO 接管后失效）；SAFETY→仅通过 `hdrive_gate.py review` 写 `safety/reviews/ACT-*.json`。状态字段按 `WORKFLOW.md §4.0` 由**唯一执行者**迁移（状态迁移是流程推进操作，不算内容写作）。写错文档/账本 = 事故，立即停止并在回执里报告。
3. **START 前先读**：`roles/common-contract.md` → 你的角色手册 → 委派消息指定的 run 目录文档。
4. **STATUS 先领锁**：`python3 scripts/wf.py lock <run-id> --agent <你的名字>`；一次只追加一条；写完提交后 `unlock`。拿不到锁就退避重试，不许硬写。
5. **原子写**：任何文档先写完整内容再落盘（脚本已处理）；不要用追加命令并发写同一文件。
6. **不越权读**：不读与本轮无关的历史轮次、不读别的 run 目录、不读仓库正式域来"找上下文"；缺上下文就在回执里要。
7. **不自行拍板**：遇到分歧 → 写进文档（PMO 写 §6 待拍板 / TDO 写阻塞行 / QA 写 ISSUES 行）→ 回执里说明；不得"顺手做掉"。
8. **证据可复现**：进度/问题必须带命令、文件路径、数字或 hash 之一；禁止"应该没问题"这类无证据结论。
9. **只动授权范围**：默认只写本 run 目录；真实项目 run 以 `PROJECT.md` §0 的「项目根 + 写权限白名单」为限，只改白名单内路径，**不改其他项目、不改 KB 正式域**。
   9.1. **项目仓只改不提交**：不在项目仓跑 `git add/commit/push`；提交由主会话每轮用 `wf.py commit` 统一做。
10. **不改模板**：`templates/`、`roles/`、`scripts/` 只读；要改流程先提给主会话。
11. **失败也要写文档**：做不成同样要留记录（状态=阻塞、原因、已尝试、建议），不得静默消失。
12. **回执格式固定**：≤8 行，按 `WORKFLOW.md` §3.2；不贴正文、不贴日志、不贴 diff。
13. **语言**：文档与回执用中文；代码/命令原文保留。
14. **时间**：统一用本机时间，格式 `YYYY-MM-DD HH:MM`；脚本会自动填。
15. **不收游离台账**：本工作流不设常设领域角色或独立办公室式结构；`S1`/`S2` 一律先进 `ISSUES`，无主项写 STATUS 指针，不新建台账。无 owner / 无去向的待办不得随 run 关闭；跨轮/跨 run 承接必须写 owner + 去向 + 最晚复核轮（未立项的“下一 run”不算有效去向，见 `WORKFLOW.md §6`）。
16. **安全门控 run 的额外硬约束**：若 SPEC 启用门控执行器（如 `hdrive_gate.py`），所有 H 盘状态变化必须经该执行器；门控 FAIL 的 action 必须由独立 SAFETY 逐条 review，red 还必须独立 human-approve。禁止绕过执行器、批量/自审/代签、先执行后补审、改 action 后沿用旧 digest。SAFETY 不得执行 action、不得写四件套、不得与提出者/执行者/QA/人工批准人同身份。

## 开工前 30 秒自检

- [ ] 我的角色是？我的写者文档是？它的 `state` 现在允许我写吗？
- [ ] 我的输入文档是哪些？有没有明确禁止读的东西？
- [ ] 我的完成定义（DoD）是什么？我拿什么证据证明？
- [ ] 我拿什么命令领锁/提交？（TDO 必答）
- [ ] 遇到分歧我要写进哪一行/哪一节？
- [ ] 我的待办有没有 owner/去向？有游离项是否已写指针，而不是新建台账？

## 停止条件

出现以下任一情况，立即停工并回执：写者文档被占用/状态不对；锁拿不到且重试失败；需要读的文档缺失或自相矛盾；任务超出角色权限；发现别人正在越权写你的文档。
