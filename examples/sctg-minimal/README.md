# SCTG minimal example

The reference kit lives in `sctg-kit/`. It contains the task-card runner, four
gates, submission schema, decision helper, and ledger helper.

```bash
python3 sctg-kit/sctg.py --help
```

For the full public kit documentation and minimal demos, see
[`SCTG-public`](https://github.com/7067567g/SCTG-public).

## Runnable demo

```bash
python3 examples/sctg-minimal/run_demo.py
```

It creates a temporary card, submission, evidence, and runs all four gates.
