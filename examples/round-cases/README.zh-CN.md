# 12 轮工作流案例

三个合成但真实的 12 轮 workflow-group 案例。每个案例都真实执行了
`wf.py new-run / append-status / state / new-round`，然后导出并脱敏。

| 案例 | 重点 |
|---|---|
| [`case-12-rounds-hardening`](case-12-rounds-hardening/README.zh-CN.md) | 12 轮加固一个小服务 |
| [`case-12-rounds-release`](case-12-rounds-release/README.zh-CN.md) | 12 轮准备一次发布 |
| [`case-12-rounds-docs`](case-12-rounds-docs/README.zh-CN.md) | 12 轮改进双语文档 |

每个案例包含 12 个 `STATUS-Round-N.md`、12 条决策、`ROUNDS.md`、
`ROUNDS.json` 和证据日志。它们是示意案例，不是真实项目数据。
