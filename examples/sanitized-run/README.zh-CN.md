# 脱敏 run 样例

一个小型合成控制面样例，用来展示真实 run 的文档形状；不包含任何项目数据、
凭证、绝对路径或 transcript。

```text
examples/sanitized-run/
  PROJECT.md            目标 / 范围 / 指标 / 轮次总结
  SPEC.md               run 专属规则
  DECISIONS.md          MAIN 决策
  STATUS-Round-1.md     TDO 进度 + 证据指针
  ISSUES.md             QA 发现
  openrig/README.md     渲染后的 bundle 位置
  sctg/submission.json  示例 submission
  sctg/gate-result.json 示例 gate result
  evidence/README.md    证据指针约定
```

这是示意样例，不是真实项目的回放。
